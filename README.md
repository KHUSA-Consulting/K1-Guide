# K1-guide-s
This document outlines the Online Standard Operating Procedures (guide) for the K1 System. 
The purpose of this guide is to provide clear and comprehensive guidelines for all users on the system’s usage, processes, and workflows. 
The guide ensures consistency and standardisation across operations, contributing to improved productivity and reduced errors.
