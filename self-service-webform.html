KHUSA Member Self-Service – User Guide

Welcome to the KHUSA Member Self-Service Case Submission Form. This guide explains how members can submit cases directly to KHUSA Consulting.

What Is This Form For?

This form enables members to submit queries and requests directly to the consultant visiting them onsite.

The self-service process helps to:

  • Ensure that member information is accurate and up to date.
  • Maintain a complete record of all submitted cases.
  • Improve case tracking and accountability.
  • Eliminate the need for consultants to create cases retrospectively for members who have already been assisted onsite.

How do members access the submission form?

1. Scan the QR Code

How do Members Submit a Case?

1. Find their record.

Search for their contact record using one of the following:

  • ID number
  • Membership number

2. Click the "Look Up Member" button.


If the Member record Exist on K1, a form with member details will be populated.

3. Complete all empty fields

The member will have the opportunity to complete their details in empty fields.

After the completion of empty fields the member must complete query details:

  • Case Reason
    1. Member One-On-One
    2. Presentation
    3. Member One-On-One & Presentation
  • Agent
    1. Select the current onsite consultant.
  • Case Description
    1. Include a description of what the member needs assistance with.
  • Attachments (Optional)

4. Click Submit Query Button


If the Member record does not Exist on K1, an empty form will be available for population.

3. Complete all empty fields

The member will have the opportunity to complete their Member details in empty fields.

  • ID / Passport Number
  • Membership Number
  • First Name
  • Last Name
  • Cell Number
  • Email

After the completion of empty fields the member must complete query details:

  • Case Reason
    1. Member One-On-One
    2. Presentation
    3. Member One-On-One & Presentation
  • Agent
    1. Select the current onsite consultant.
  • Case Description
    1. Include a description of what the member needs assistance with.
  • Attachments (Optional)

4. Click Submit Query Button


5. Sucesfull Submision

After sucessful submision the member will:

  1. Be navigated to a page containing a sucessful submision message with the case reference number.
  2. Receive an email to the email address populated on the form containing a sucessful submision message with the case reference number.
